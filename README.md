# Salawu Abdulhameed — Portfolio

A responsive developer portfolio built with HTML, CSS and JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a browser.

For development, you can also use VS Code's Live Server extension.

## Files

- `index.html` — page structure and content
- `style.css` — responsive design and styling
- `script.js` — mobile navigation and dynamic year

## Before publishing

The portfolio currently features NodeForge and the Netflix sign-up page. Keep their
descriptions and repository links up to date as the projects evolve. The contact
email is set in `index.html`; add professional profile links or a CV if desired.

## Suggested next full-stack upgrade

Add a React/Next.js frontend, a Node.js/Express API, PostgreSQL database, contact-form endpoint, project management/admin dashboard, validation, and deployment.
